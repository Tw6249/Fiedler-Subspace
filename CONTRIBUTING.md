# Contributing

Thanks for helping improve Fiedler-Subspace.

## Before opening a pull request

1. Keep changes scoped to one method, experiment, or documentation task.
2. Run the relevant tests from `current_version/distributed_fiedler_violation_free_soc`.
3. For new numerical results, include the exact command, configuration, and output directory.
4. Never commit raw videos, ROS bags, credentials, or generated build trees.
5. Explain whether a result is simulation evidence, replay evidence, or hardware evidence.

Please open an issue before changing the public experiment entry points or the interpretation of safety metrics.
